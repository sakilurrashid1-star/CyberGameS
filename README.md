# 🛡️ Cyber Defense Command

A polished browser-based cyber defense game built in plain HTML, CSS, and JavaScript. Defend the network core from escalating cyberattacks, neutralize hostile assets, collect powerups, and survive each wave.

## 🎮 Mission Overview

Cyber Defense Command is a tactical defense game where the operator controls a defensive drone at the edge of the network perimeter. Incoming adversarial traffic, malware, and stealth payloads threaten the integrity of critical systems. The objective is to block attacks, maintain system health, and survive increasingly hostile wave conditions.

## 🚀 How to Play

- Move with `WASD` or arrow keys.
- Aim with the mouse.
- Fire with left click or the space bar.
- Pause with `P`.
- Collect repair kits (`+`) and shield cells to stabilize the network.

## 🧠 Objectives

- Prevent hostile threats from breaching the core network.
- Eliminate incoming malware and botnet traffic.
- Survive each wave and increase score.
- Maintain infrastructure integrity above zero.
