## 🌟 প্রধান ফিচারসমূহ (Key Features)

### ১. 🎓 ফাউন্ডেশনাল সাইবার ডিফেন্স একাডেমি (লেভেল ১ থেকে ৪)
* **২০টি বাস্তবসম্মত সাইবার সিকিউরিটি মিশন**: পাসওয়ার্ড ক্রিপ্টোগ্রাফি, ফিশিং ডিটেকশন, ২-ফ্যাক্টর অথেনটিকেশন, SQL ইনজেকশন ডিফেন্স, ম্যালওয়্যার আইসোলেশন থেকে শুরু করে এন্টারপ্রাইজ জিরো-ট্রাস্ট আর্কিটেকচার পর্যন্ত।
* **Duolingo-স্টাইল জিগজ্যাগ লার্নিং পাথওয়ে**: প্রতি ধাপে পয়েন্ট (XP), রিয়েল-ওয়ার্ল্ড কেস স্টাডি ও CISO ডিব্রিফিং।
* **ট্যাকটিক্যাল হিন্ট সিস্টেম**: আটকে গেলে এক্সপি খরচে বিশেষজ্ঞদের মতো প্রম্পট পরামর্শ।

### ২. ⚔️ লেভেল ৫: লাইভ ১v১ সাইবার ডুয়েল অ্যারেনা (Live 1v1 Arena)
* **রিয়েল-টাইম মাল্টিপ্লেয়ার ব্যাটল**: লেভেল ৪ কমপ্লিট করলেই আনলক হয় হাই-ভোল্টেজ 1v1 যুদ্ধক্ষেত্র।
* **কুইকম্যাচ ও প্রাইভেট রুম কোড**: সরাসরি অন্য কোনো অনলাইন খেলোয়াড়ের সাথে মুহূর্তেই ম্যাচমেকিং অথবা ৬-ডিজিটের কোড শেয়ার করে বন্ধুদের সরাসরি চ্যালেঞ্জ!
* **লাইভ ইন-গেম কমব্যাট চ্যাট ও ট্যাকটিক্যাল টনট (Live In-Game Chat)**:
  * মোবাইল ফ্রেন্ডলি ১-ট্যাপ কুইক টনট: `🛡️ Nice Firewall!`, `⚡ Zero-Day Incoming!`, `💥 Brace for DDoS!`, `🤝 GG WP!`
  * কাস্টম মেসেজিং টেক্সটবক্স।
* **অ্যানিমেটেড লেজার স্ট্রাইক ও শিল্ড মেকানিক্স**: ভুল ডিফেন্সে নিজের শিল্ড লিক, সঠিক জবাবে প্রতিপক্ষের সার্ভারে লেজার অ্যাটাক!

### ৩. 🪪 পারসিস্টেন্ট অ্যাকাউন্ট ও প্রোফাইল ফটো আপলোড
* **আলাদা রেজিস্টার ও লগইন ট্যাব**: কোনো জটিলতা ছাড়াই নিজস্ব **Call Sign (ইউজারনেম)** ও **৪-ডিজিট সিক্রেট পিন** দিয়ে একাউন্ট তৈরি।
* **কাস্টম ছবি আপলোড**: ফোন ক্যামেরা, গ্যালারি বা কম্পিউটার থেকে সরাসরি ছবি আপলোড। ক্লায়েন্ট-সাইড ক্যানভাস কম্প্রেশনের মাধ্যমে ১২৮x১২৮ অপ্টিমাইজড রেজোলিউশনে ছবি সেভ হয়।
* **♂️ ও ♀️ জেন্ডার আইডেন্টিফিকেশন**: পুরুষ ও নারী প্লেয়ারদের জন্য আলাদা স্টাইলিং ও ভিজ্যুয়াল ব্যাজ (`♂️ Male` / `♀️ Female`)।

### ৪. 🏆 ভেরিফায়েড ন্যাশনাল ট্রফি লিডারবোর্ড (Elo Rating)
* কোনো ফেক বট প্লেয়ার নয়; প্রকৃত ট্রফি ও অর্জিত এক্সপির ভিত্তিতে সারা বাংলাদেশের লাইভ র‍্যাংকিং।
* অপরেটিভ সার্চ করে সরাসরি ডসিয়ার দেখা ও ১-ক্লিকে চ্যালেঞ্জ পাঠানো।

### ৫. 🎖️ অফিসিয়াল সাইবার অপরেটিভ আইডি কার্ড জেনারেটর
* গেম থেকেই সরাসরি ক্যানভাসে জেনারেট করুন নিজের ছবি, জেন্ডার, ট্রফি ও সিকিউরিটি র‍্যাংকসহ **PNG ID Badge** এবং সোশ্যাল মিডিয়ায় শেয়ার করুন।

### ৬. 📲 প্রগ্রেসিভ ওয়েব অ্যাপ (PWA) — মোবাইল ফ্রেন্ডলি
* অ্যান্ড্রয়েড এবং আইফোনে কোনো অ্যাপ স্টোর ছাড়াই হোম স্ক্রিনে ফুল-স্ক্রিন অ্যাপ হিসেবে ইনস্টল করে খেলার পূর্ণ সুবিধা।

## 🚀 লোকাল মেশিনে কীভাবে রান করবেন (How to Run)

### মেথড ১: ফুল-স্ট্যাক নোড সার্ভার (Recommended)
```bash
# ১. রিপোজিটরি ক্লোন করুন
git clone https://github.com/sakilurrashid1-star/CyberGameS.git
cd CyberGameS

# ২. ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# ৩. সার্ভার স্টার্ট করুন
npm start
```
ব্রাউজারে ওপেন করুন: **`http://localhost:3000`**

### মেথড ২: সরাসরি ব্রাউজারে রান
যেকোনো ব্রাউজারে `index.html` ফাইলটি ওপেন করলেই একাডেমি ও গেম স্বয়ংক্রিয়ভাবে ক্লাউড ব্যাকএন্ডের সাথে সিঙ্ক হয়ে চলবে!
